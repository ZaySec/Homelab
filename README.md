# ZaySec Homelab
The official homelab hosting all of my services. Everything, and I mean everything was looked into and modified, from the firmware / bios to the placement of the PC for airflow and aesthetics. 

Current Services:
1. OS: Proxmox
2. Name: OPNSense -> Function: Firewall, DHCP Server, Network Logs, and Routes (For Site-to-Site VPN) 
3. Name: Pihole -> Function: DNS Sinkhole (Network Wide Ad-blocker) 
4. Name: Tailscale -> Function: Everything VPN
5. Name: Immich -> Function: Cloud Photos and ACL
6. Name: Debian LXC -> Function: Rust Devlopment
